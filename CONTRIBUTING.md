# Contributing

This catalog takes contributions as issues. Pull requests from outside are not accepted: pull request creation is restricted to collaborators of the repository.

## Open an issue

Use the form that fits at [Issues > New issue](https://github.com/Sync-Labs-team/plugins/issues/new/choose):

- Bug: the catalog does not add, list or install a plugin as the README says.
- Plugin request: a plugin you would like to see in the catalog.

Search the existing issues first. If one covers it, add what is new as a comment.

## What makes a good issue

- The command you ran and the exact output.
- CLI and its version (`claude --version`, `codex --version`) and your operating system.
- Nothing private: no tokens, secrets, client or project names, or machine paths with your user name.

## Scope

In scope: the catalog files, the install steps in the READMEs, which plugins are listed. A bug inside a plugin belongs in that plugin's repository, linked from the table in the README.

Security problems are not issues: see [SECURITY.md](SECURITY.md).
