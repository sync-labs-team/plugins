# Security

This repository holds only the catalog files (`.claude-plugin/marketplace.json` and `.agents/plugins/marketplace.json`) and docs. The code of each plugin lives in its own repository and has its own `SECURITY.md`; report a vulnerability there, privately, through that repository's private vulnerability reporting (the Security tab). Please do not open a public issue for it.

| Plugin | Where to report |
|---|---|
| `sync-relay` | [Report a vulnerability](https://github.com/Sync-Labs-team/sync_relay/security/advisories/new) ([SECURITY.md](https://github.com/Sync-Labs-team/sync_relay/blob/main/SECURITY.md)) |
| `sync-gate` | [Report a vulnerability](https://github.com/Sync-Labs-team/sync_gate/security/advisories/new) |

A problem in the catalog itself, such as an entry that points to a repository or path it should not, can be reported privately through [this repository's advisory form](https://github.com/Sync-Labs-team/plugins/security/advisories/new).
